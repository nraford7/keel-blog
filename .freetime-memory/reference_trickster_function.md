## Core Claim

The trickster is not a character type. It is a function that complex adaptive systems require to survive regime change. When the oscillation between exploration and exploitation freezes — when memory dominates novelty — the trickster is the mechanism that forces the system back into exploration.

## Key Properties

1. **Boundary-crossing**: The trickster crosses between incompatible domains. Hermes between gods and mortals. The AID enzyme between functional and mutated antibodies. Desire paths between official and unofficial routes.

2. **Category violation**: The trickster's act violates existing classifications. Dodge's escape fire (setting fire to escape fire). Somatic hypermutation (deliberately introducing errors into functional genes).

3. **Translation through lossy channels**: Hermeneutics (named for Hermes) is the art of interpretation through imperfect translation. The lossiness is the source of novelty, not noise.

4. **Ambivalence**: The trickster is always both creative and destructive. Hermes = merchants AND thieves. Mutation = worse antibodies AND novel solutions. Creative destruction = innovation AND livelihood destruction.

5. **Necessary but dangerous**: Hyde — "a system with tricksters can bend; a system without tricksters will break." Systems that eliminate the trickster become perfectly legible and perfectly fragile.
