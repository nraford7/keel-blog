## Source
Pyyhtinen & Zavos (2025), "Containment and Leakage: Notes on a General Containerology," *Theory, Culture & Society*. Key claim: containment and leakage are co-constitutive, not opposed. All containers are provisional, contextual, leaky.

## Four Types of Leakage

1. **Structural** — container never closed. Invisible from inside (overflow clipping masks it). Catastrophic at boundaries. The missing `</div>`.
2. **Adaptive** — selective permeability. Cell membranes, immune tolerance (central + peripheral), functional organizational boundaries. The healthy state.
3. **Trickster** — deliberate boundary violation that restarts frozen patterns. Germinal center dark zone, Hyde's trickster figures. Reveals boundaries were always membranes.
4. **Antigenic** — old containers crowd out new ones. Original antigenic sin, Weick's cosmology episodes, keloid scarring. Memory floods the space reserved for novelty.

- Trickster function → Type 3 is what the trickster does

## Structural Principle
Every container is a membrane whose leakage pattern determines whether the system adapts, freezes, or collapses. The question is never whether it leaks, but how.
